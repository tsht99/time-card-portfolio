# AI エージェントによる計画と実行

変更要求から実装完了までを連続して扱う場合の合成 workflow を定義する。

この文書は [計画 workflow](./plan.md) と [実行 workflow](./execute.md) の責務を再定義しない。

## 適用条件

確定済みの実装計画がまだ存在しない変更要求では、まず `plan.md` の完了条件を満たす計画を作る。

計画が `plan.md` の完了条件を満たした状態は、そのまま `execute.md` の入力条件を満たす。人による計画レビューを待つよう明示されていない限り、計画確定は停止条件ではなく実行への遷移条件とする。

人による計画レビューが明示的に必要な場合は、承認または修正された計画だけを `execute.md` の入力として扱う。

すでに確定済みの実装計画が与えられている場合、この合成 workflow を経由する必要はなく、`execute.md` の入力として直接扱う。
