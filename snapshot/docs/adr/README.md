# ADR

現行システムの重要な設計判断のうち、妥当な代替案があり、選択理由と受け入れたトレードオフを後から説明する価値があるものを記録する。

一般的な設計原則、コードから分かる実装詳細、単なる構成・命名・設定の整理は ADR にしない。現行仕様と構成は [要件定義書](../要件定義書.md)・[設計書](../設計書.md)を Source of Truth とする。
