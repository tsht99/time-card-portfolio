# ユーザーを管理する

## 利用者を確認する

1. 管理画面で「ユーザー」を開きます。
2. 一覧からスタッフまたは管理者を選び、詳細を開きます。
3. 役割、利用状態、表示名を確認します。

<Screenshot name="admin-users.png" alt="役割や利用状態、表示名を確認できるユーザー一覧" />

スタッフの利用状態は「承認待ち」「利用中」「利用停止」で表示されます。管理者とスタッフは役割で区別できます。

<Screenshot name="admin-user-detail.png" alt="ユーザー詳細に表示された役割、利用状態、表示名" />

## スタッフを承認・利用停止・再有効化する

1. 対象スタッフの詳細を開きます。
2. 画面の操作を選びます。承認待ちの場合は「承認する」、利用中の場合は「利用を停止する」、利用停止の場合は「再有効化する」を選びます。
3. 確認画面で対象と変更内容を確かめてから確定します。

管理者が利用状態を変更できる対象はスタッフです。承認待ちから利用停止へ直接変更することはできません。承認を確定するには、有効な表示名が設定されている必要があります。表示名が未設定、文字数が範囲外、または利用中・利用停止の利用者と重複している場合は承認できないため、先に表示名を設定・変更してください。利用停止にすると、スタッフは TimeCard を利用できなくなります。再有効化後も、スタッフはあらためて LINE で本人確認する必要があります。

## 表示名を変更する

1. 対象ユーザーの詳細で表示名の編集を開きます。
2. 前後の空白を除いて 1〜100 文字の名前を入力し、保存します。

表示名は前後の空白を除いて 1〜100 文字である必要があります。承認待ちスタッフは表示名が未設定のままでも保持できますが、承認時には有効な表示名が必要です。承認前に設定しておくか、設定がなければ承認操作の前に登録してください。承認後も表示名を変更できます。

利用中・利用停止の利用者どうしでは表示名を重複できません。承認待ちの間は重複する表示名を設定できますが、その名前が利用中または利用停止の利用者と重複している場合は承認できません。重複の案内が表示された場合は、別の名前へ変更してください。

スタッフの表示名と管理者本人の表示名は変更できます。他の管理者の表示名は変更できません。管理者の利用状態もこの画面から変更できません。
