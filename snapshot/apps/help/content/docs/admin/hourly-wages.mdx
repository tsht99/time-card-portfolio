# 時給を管理する

## 時給設定を開く

1. 「ユーザー」から対象者の詳細を開きます。
2. 「時給設定」を選びます。
3. 曜日と祝日、昼・夜ごとの時給を確認します。

<Screenshot name="admin-hourly-wages.png" alt="曜日・祝日と昼・夜ごとの時給、適用開始日を示す時給設定画面" />

勤怠詳細から時給設定を開いた場合は、その利用者と勤怠日に適用される時給を確認できます。設定画面の利用者を別の人へ切り替えることはできません。

スタッフと操作する管理者本人の時給は変更できます。他の管理者の時給は確認のみです。

## 時給をまとめて改定する

1. 時給設定で編集を開きます。
2. 共通の適用開始日を指定します。
3. 曜日または祝日、昼・夜のうち、変更する欄だけに時給を入力します。
4. 入力内容を確認して保存します。

<TutorialVideo
  name="hourly-wage-rule-bulk-edit.mp4"
  label="管理者が時給をまとめて改定する操作説明動画"
/>

時給は 1 時間あたり 0〜99,999 円の整数です。0 円も有効な時給です。空欄にした欄は変更されません。複数の変更欄はまとめて保存されます。条件と適用開始日が同じルールを重ねて登録することはできません。

時給は勤務日、勤務区分、曜日または祝日、適用開始日から決まります。祝日は曜日のルールより祝日のルールが優先されます。対象日に有効なルールがない場合は「未設定」となり、0 円の時給とは区別されます。

## 登録済み時給を訂正・削除する

時給設定から「時給履歴」を開くと、適用開始日ごとの変更内容を確認できます。訂正する場合は対象ルールの時給、勤務区分、曜日・祝日、適用開始日を確認して編集します。削除する場合は対象ルールの内容を確かめてから削除します。

<Screenshot name="admin-hourly-wage-history.png" alt="適用開始日ごとの登録済み時給と編集・削除操作を示す時給履歴" />

登録済みルールの訂正・削除によって、過去の勤怠に適用される時給や給与見込みが変わることがあります。変更前に対象ルールと適用開始日を確認してください。
