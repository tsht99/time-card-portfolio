# 未登録勤怠を新規作成する

出勤・退勤の両方を記録し忘れるなど、勤怠が存在しない場合は、管理者が勤怠一覧から新規作成します。

1. 勤怠一覧から新規作成を開きます。
2. 対象者と勤務区分（昼または夜）を選びます。
3. 確認できた実際の出勤日時と退勤日時を入力します。
4. 入力内容を確認して作成します。

<Screenshot name="admin-attendance-create.png" alt="対象者、勤務区分、出勤日時、退勤日時を入力する勤怠作成画面" />

作成対象は、利用中または利用停止中のスタッフと、操作する管理者本人です。承認待ちのスタッフや他の管理者は対象にできません。

勤務日は出勤日時の日本時間の日付で決まります。退勤日時は出勤日時と同じか後にしてください。同じ利用者の別の勤怠と勤務時間が重なる場合は作成できません。同じ日・同じ勤務区分の勤怠があることだけでは作成を妨げません。

日時を確認できない場合は、現在時刻やシフトなどから推測して作成しないでください。作成した勤怠は通常の勤怠として一覧と給与見込みに反映され、その後は訂正・取消の対象になります。
