# 給与見込みを確認する

1. 管理画面で「給与見込み」を開きます。
2. 前月・次月へ移動するか、対象月を選びます。
3. 利用者ごとの給与見込みと「要確認」の表示を確認します。
4. 内容を調べる利用者の給与見込み詳細を開きます。

  name="admin-payroll-estimate-list.png"

/>

給与見込みは、勤怠ごとの勤務時間と、その勤務日に有効な時給から算出されます。勤怠は出勤日（日本時間）を基準に月へ含まれます。翌日の退勤時刻は 24 時を超えて表示されることがあります。同じ日に複数の勤怠がある場合も、勤怠ごとに確認できます。

## 「要確認」がある場合

給与見込み一覧の「要確認」は、算定に不足がある利用者を示します。原因は給与見込み詳細で確認してください。

- 退勤時刻がないなど、勤務時間を確定できない勤怠は勤務時間・給与見込みに含まれません。
- 勤務時間を確定できても時給が未設定の勤怠は、勤務時間には含まれますが給与見込みには含まれません。
- 取消済み勤怠は給与見込みに含まれません。
- 勤怠ごとの表示額と月の合計に丸め差がある場合は、給与見込み詳細の「端数調整」で確認できます。

退勤時刻が未登録と表示されても、現在も勤務中とは限りません。勤怠の内容を確認し、必要に応じて勤務時間の訂正や時給設定を行ってください。

TimeCard の給与見込みは、記録された勤務時間と時給に基づく集計額です。税、社会保険、源泉徴収、法定割増、給与明細などを含む最終的な給与計算ではありません。
