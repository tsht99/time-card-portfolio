# 勤怠を訂正・取消する

## 勤怠を訂正する

1. 勤怠詳細で、対象者、出勤日、勤務区分、現在の出退勤時刻を確認します。
2. 「訂正」を開き、確認できた正しい勤務区分・出勤日時・退勤日時を入力します。
3. 入力内容を確認して保存します。

勤務中の勤怠は、正しい退勤日時が確認できれば退勤時刻を補記して完了できます。登録済みの勤怠を退勤前の状態へ戻す操作はありません。誤って早く退勤した場合は、実際の勤務終了後に確認できた正しい退勤日時へ訂正します。

## 誤登録を取り消す

1. 勤怠詳細で、取り消す勤怠全体と内容を確認します。
2. 「取消」を選び、確認画面の対象と説明を確認して確定します。

取消は出勤と退勤を含む勤怠全体を無効にする操作です。出勤だけ、または退勤だけを取り消すことはできません。取消後は訂正・再取消・復活ができないため、確定前に対象をよく確認してください。取消済み勤怠は履歴で確認でき、給与見込みには含まれません。

## 変更できる対象

スタッフと管理者本人の勤怠は変更できます。他の管理者の勤怠は閲覧のみです。正しい日時が分からない場合は推測して保存せず、対象者や記録を確認してください。競合や最新状態に関する案内が表示された場合は、詳細を開き直して現在の内容を確認してから操作します。
