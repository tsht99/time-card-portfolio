# 勤怠を確認する

1. 管理画面で「勤怠」を開きます。
2. 必要に応じて検索条件を開き、期間、利用者、勤務区分、勤怠の状態を指定して検索します。
3. 一覧から確認したい勤怠を選び、詳細を開きます。

<Screenshot
  name="admin-attendance-list.png"
  alt="期間や利用者で絞り込んだ勤怠一覧と各勤怠の状態"
/>

一覧では、勤務中・完了済み・取消済みの勤怠を確認できます。出勤日ごとにまとめて表示され、翌日の退勤時刻は出勤日からの経過が分かるよう 24 時を超える時刻で表示されることがあります。

詳細では、登録内容、変更履歴、変更した操作者、適用時給、給与見込み、または算出できない理由を確認できます。

<Screenshot
  name="admin-attendance-detail.png"
  alt="勤怠の出退勤時刻、変更履歴、適用時給と給与見込みを示す詳細画面"
/>

退勤時刻が `--:--` と表示されている場合は退勤未記録を示しますが、それだけでは現在も勤務中とは判断できません。勤務状態や変更履歴などを詳細で確認してください。取消済み勤怠は履歴に表示されますが、給与見込みの対象にはなりません。

スタッフと自分自身の勤怠は変更できます。他の管理者の勤怠は詳細や履歴を確認できますが、変更できません。
