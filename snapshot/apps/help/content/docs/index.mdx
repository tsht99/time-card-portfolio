# TimeCard 利用者ガイド

TimeCard で出勤・退勤を記録する方法、勤怠を確認・管理する方法、給与見込みを確認する方法を案内します。

## ガイドを選ぶ

- [ログイン・利用開始](/getting-started)
- [スタッフ向けの操作](/staff)
- [管理者向けの操作](/admin)
- [よくあるケース](/common-cases)

## まず確認すること

正しい日時が分からないときは、時刻を推測して記録しないでください。当日の出勤・退勤はスタッフが現在の勤務状態に合う操作で記録し、前日以前の記録や登録済み勤怠の変更は管理者へ依頼します。
