# ログイン・利用開始

## ログインする

TimeCard にアクセスすると LINE による本人確認が行われます。画面の案内に沿って LINE で本人確認してください。認証が切れたときは、再度本人確認が必要です。

LINE の本人確認が完了しただけでは、TimeCard の利用が承認されたとは限りません。利用者の状態に応じて、次のように利用を開始します。

| 画面に表示される状態 | 次にすること                                                                                 |
| -------------------- | -------------------------------------------------------------------------------------------- |
| 承認待ち             | 管理者の承認を待ちます。承認された後、もう一度 TimeCard にアクセスして本人確認してください。 |
| 利用中               | 勤怠画面を利用できます。                                                                     |
| 利用停止             | 勤怠画面は利用できません。管理者に利用状態を確認してください。                               |

LINE 認証の失敗と、本人確認後の承認待ちは別の状態です。画面の案内を確認して対応してください。

## 表示名について

TimeCard の表示名は業務で利用する名前です。初回登録後は LINE のプロフィール名とは別に管理されます。表示名の変更が必要な場合は管理者に依頼してください。

利用停止から再度利用中になった場合も、以前のログイン状態は使えません。あらためて本人確認してください。
