# 出勤する

1. 打刻画面で、現在の勤務状態を確認します。
2. 打刻時刻に実際の出勤時刻を入力します。
3. 昼または夜を選んで出勤します。

## 出勤できる状態

現在勤務中の勤怠がないときに出勤できます。同じ日に同じ勤務区分の勤怠がすでにあっても、現在勤務中でなければ次の出勤を記録できます。

打刻画面では、画面を開いた時点の日付（例: 2026年1月1日（木））が時刻入力欄の左側に表示されます。日付は表示専用で、時刻だけを編集できます。打刻すると表示中の日付と時刻が日本時間として記録されます。日付がサーバー上の日付と一致しない場合は再読み込みが必要です。そのため、前日以前の出勤忘れを通常打刻で追加することはできません。

すでに勤務中と表示されている場合は新しい出勤を記録できません。画面を開いた後に状態が変わった可能性があるときは、最新の状態を確認してください。
