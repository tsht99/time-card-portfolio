# 退勤する

1. 打刻画面で、勤務中の状態と勤務区分を確認します。
2. 打刻時刻に実際の退勤時刻を入力します。
3. 退勤を選びます。

退勤は勤務中の勤怠がある場合に記録できます。勤務中の勤怠がない状態から退勤することはできません。

打刻画面には、画面を開いた時点の日付が表示されます。日付は表示専用で、時刻だけを編集できます。打刻すると表示中の日付と時刻が日本時間として記録されます。日付がサーバー上の日付と一致しない場合は再読み込みが必要です。前日から続いている勤務も、表示中の日付の実際の退勤時刻で退勤できます。日付が変わっただけでは勤務中の勤怠は終了しません。

実際の退勤日時が分からないときは、時刻を推測して入力せず、管理者に確認してください。
