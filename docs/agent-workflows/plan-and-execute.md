# AI エージェントによる計画と実行

変更要求から実装完了までを連続して進める場合の合成ワークフローを定義する。

この文書では計画と実行の詳細を重複して定義しない。

1. [計画ワークフロー](./plan.md) に従って、実行可能な実装計画を作る。
2. 人による計画レビューを待つよう明示されていない場合は、計画作成後に停止せず、その計画をそのまま [実行ワークフロー](./execute.md) の入力として実行する。
3. 人による計画レビューが必要な場合は、計画を出力した時点で停止し、承認または修正後に `execute.md` から再開する。

すでに確定済みの実装計画が与えられている場合は、この合成ワークフローを経由せず `execute.md` だけを使用する。
